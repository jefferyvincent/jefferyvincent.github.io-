Decisions worth writing down

The trading agent that doesn't get the last word

The easy path
Let the model decide. Prompt it to be careful and hope the prompt holds.
What shipped
An LLM committee debates a trade and a judge model returns a verdict — then that verdict hits a deterministic rules gate that can overrule it and can't be argued with. The autonomous mode is real, but it acts inside a fence of portfolio circuit breakers and a daily-loss kill switch that latches until cleared by hand. Exits are never blocked. Every place a model touches money, non-probabilistic code gets the final say.

A backtest that runs the live trader's exit code

The easy path
Tune a strategy until the backtest looks great, then rewrite the exit logic for live trading and trust that they match.
What shipped
One exit rule, one code path, shared by the backtester and the live bracket manager — so a backtest exercises the exact logic that manages a real position. On top sits a research loop where a local model proposes the next parameter grid from an audited allow-list (no generated code), a walk-forward optimizer scores it out of sample, and a held-back lock-box validates the winner exactly once. Each layer referees the one above it.

Python · Ollama · Alpaca · SQLite · Obsidian

Then I checked the subscriber count, found zero, and sunset it. The infrastructure got reused. The sunk cost didn't get honored.
