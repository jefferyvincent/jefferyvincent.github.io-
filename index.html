Decisions worth writing down

The trading agent that can't place an order

The easy path
Give the agent broker credentials and let it trade. It's the demo everyone wants to see.
What shipped
A read-only scanning worker that can only produce proposals, and a separate approval step that a human has to clear before anything reaches the broker. No code path exists that places an order on its own. The split is the product, not a safety feature bolted on top.

Python · FastAPI · Railway · Alpaca

Giving a local model a shell, safely

The easy path
Let the model call tools directly. Fast to build, and fine right up until it isn't.
What shipped
A voice assistant running entirely on local hardware, where every tool call surfaces in a browser modal showing exactly what's about to run. I approve or I don't. Latency cost was real; the tradeoff was worth it.

FastAPI · faster-whisper · Ollama · Coqui XTTS

One entitlement model, three billing systems

The easy path
Handle StoreKit, Play Billing, and Stripe where each one shows up in the app.
What shipped
A single source of truth for what a user is entitled to, with the three billing systems reduced to adapters feeding it. Restore, refund, and cross-platform purchase stopped being three separate bug surfaces.
